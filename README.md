# ClipVault - Modern Unlimited Clipboard Manager for Android

ClipVault is an intelligent, privacy-first clipboard manager built with modern Android tech stack:
- **Kotlin 2.0.0** & **Jetpack Compose + Material 3** (Signature Dark Mode + Crisp Pure-White Light Mode)
- **Two-Tier ClipVaultFilterBar & Inline ClipCardHeader** for clean custom user tags
- **Room Database** with **SQLite FTS4** Full-Text Search & **Google Drive / JSON Cloud Backup & Restore**
- **Persistent `ClipMonitorService` (`START_STICKY` + `dataSync` + `Mutex.withLock`)** for 24/7 background capture
- **Android 13+ Runtime Notification Permission & Battery Optimization Handling**
- **Custom User Tags**, **Dynamic Search Highlighting**, **Multi-Select Batch Operations**, & **Quick Settings Tile**
- **Dagger Hilt** Dependency Injection
- **AndroidX Security & BiometricPrompt** (Hardware-backed AES-256 GCM Vault)
