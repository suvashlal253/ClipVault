## ✨ Features
- **Local Room Database + FTS4**: Fast full-text keyword search across unlimited clip history.
- **Background Auto-Capture (Android 10 - 15 Compliant)**:
  - Uses `AccessibilityService` to legally detect and capture system clipboard changes from background without root.
  - Optional `ForegroundService` with Quick Settings Tile for one-tap capture.
- **Smart Categorization Engine**:
  - Automatically identifies URLs, Emails, Phone numbers, 2FA/OTPs, Source Code (Kotlin, SQL, JSON), Hex Colors, and High-entropy secrets.
- **Biometric Secure Vault**:
  - Hardware-backed AES-256 GCM encryption via `AndroidKeyStore`.
  - Unlocked with fingerprint, face recognition, or device PIN.
- **Pinned / Favorites Section**:
  - Keep important clips permanently pinned at top of list.
